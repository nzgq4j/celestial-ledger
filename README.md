# Celestial Ledger

A privacy-first browser-based Western tropical natal chart application built with Next.js, TypeScript, React, Tailwind CSS, Swiss Ephemeris-compatible calculations, historical IANA time-zone resolution, verified geocoding, deterministic chart validation, and the OpenAI Responses API.

The complete project source is committed in this repository. See the expanded README content in the next commit for setup, architecture, testing, privacy, deployment, and licensing guidance.
