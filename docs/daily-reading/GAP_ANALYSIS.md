## Confirmed release-one gaps

The minimum complete registered-user feature cannot be achieved by enlarging the public Sun-sign horoscope. It requires all of the following as one coherent vertical slice:

1. Time-windowed celestial facts and transit-to-natal calculations.
2. Deterministic signals, themes, contradictions, and temporal states.
3. A strict daily analytical payload with immutable evidence.
4. A private, idempotent daily persistence and job lifecycle.
5. Controlled localized narrative generation and validation.
6. A private account/viewer experience with the BLUF at the top.

The feature may omit unsupported current angles, annual techniques, calendar integration, and unrestricted user text without becoming generic, provided those omissions are explicit in the method profile and the long-term section uses validated slow-moving transit windows.
