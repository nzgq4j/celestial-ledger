# Test strategy

Pull requests must run formatting, typecheck, ESLint, Vitest, a production build, dependency audit, secret scan, and license inventory. Calculation releases additionally require the Node server ephemeris gate.

Later phases add disposable Supabase migration/RLS tests, Stripe test-mode webhook contracts, authenticated API ownership tests, report evidence integrity, browser accessibility, Future Trends fixtures, and Recovery Reflection safety evaluations. Tests must never target production rows or the previously inspected Docker container.

The planetary fixture suite executes eleven bodies for three UTC dates with a maximum 0.2-degree tolerance, and the Node runtime gate executes the production package. USNO-backed fixtures validate local apparent sidereal time, Ascendant, Midheaven, equal houses, cusp boundaries, DST behavior, high latitudes, historical second-based offsets, unknown time, and motion reversals. The supported production date range is 1800–2050.
