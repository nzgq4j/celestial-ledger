# ADR 0001: server-authoritative paid calculations

Status: accepted, implementation in progress.

Free charts may calculate in the browser for responsiveness. Paid reports must recalculate from normalized birth input in a supported Node runtime and persist versioned evidence. Client placements are never accepted as report evidence.

The owner approved Astronomy Engine with a Celestial Atlas-owned astrology layer on 2026-08-02. Astronomy Engine 2.1.19 is pinned, its MIT notice is preserved, the former Swiss packages are removed, and `npm run test:ephemeris-server` passes. Equal houses beginning at the Ascendant replace Placidus so no AGPL house implementation is carried forward. USNO-backed angle and equal-house fixtures establish the supported 1800–2050 production range.
