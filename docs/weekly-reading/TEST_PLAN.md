# Weekly reading test plan

## Required coverage

- ISO Monday start, seven dates, month/year/leap boundaries, and invalid starts.
- Deterministic cache/analysis; profile, week, time-zone, locale, and version sensitivity.
- Seven evidence-linked day records and resolvable BLUF/section evidence.
- Unknown-time exclusion of houses and angles across the week.
- Anonymous, cross-origin, malformed, oversized, non-owner, expired, and non-primary profile rejection.
- Free denial; Personal/Premium authorization through normalized server state and existing grace rules.
- Rollout-disabled behavior without weekly-table reads.
- RLS/BOLA coverage for list, detail, PDF, and deletion.
- Canonical duplicate and concurrent-request convergence.
- One consumption after success; no consumption on validation/persistence failure.
- Four-locale key parity and dashboard rollout/upsell/ready/history states.
- Viewer/PDF BLUF, day map, priorities, limitations, evidence, keyboard, focus, responsive, contrast, and reduced-motion behavior.

Release requires formatting, typecheck, lint, full tests, build, dependency/security audit, license review, ephemeris fixtures, safety evaluations, accessibility tests, migration dry run, database advisors, backup confirmation, forward recovery review, and explicit production approval.
